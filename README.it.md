**HideMyWindows** è un'applicazione per Microsoft Windows che ti permette di **nascondere le finestre del desktop dai metodi di cattura schermo** (screenshot, registrazioni video, software di streaming come OBS).  
È progettata per **utenti attenti alla privacy, streamer e studenti** che desiderano un controllo migliore su ciò che gli altri possono vedere durante la condivisione dello schermo.

---

## ✨ Funzionalità

- 🔒 **Nascondi finestre da screenshot e registrazioni** - 🎯 **Target per finestra, processo o nome** (supporta anche la corrispondenza regex)  
- ⚡ **Regole finestre automatiche** – nascondi automaticamente i programmi all'avvio  
- 🖥️ **Interfaccia utente moderna ed elegante** che utilizza [lepoco/WPFUI](https://github.com/lepoco/wpfui)  
- 🔄 **Modalità background** – esegui silenziosamente nell'area di notifica  
- 🚀 **Nascondi avvio rapido** per una protezione della privacy veloce  
- ⚙️ Opzioni configurabili:  
  - Nascondi **HideMyWindows** stesso  
  - Mostra/nascondi nella barra delle applicazioni  
  - Riduci a icona nell'area di notifica  
  - Metodi di monitoraggio processi e finestre

## 🚀 Utilizzo

1. Avvia **HideMyWindows**.
2. Usa lo strumento **Trova Finestra** o inserisci manualmente un PID / nome del processo.
3. Trova il tuo processo e nascondilo!
4. Applica le **regole finestre** per nascondere automaticamente le app.
5. Riduci a icona nell'area di notifica e lascialo funzionare in background.

## ⚙️ Configurazione

HideMyWindows non richiede alcuna configurazione esterna. Le impostazioni vengono salvate automaticamente all'interno dell'applicazione.

Le opzioni configurabili includono:
- Nascondi automaticamente HideMyWindows stesso
- Esegui in background (modalità area di notifica)
- Mostra/Nascondi icona nella barra delle applicazioni
- Metodo di monitoraggio processi
- Metodo di monitoraggio finestre
